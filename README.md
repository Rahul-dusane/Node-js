# 🚀 Node.js Development Journey & Projects

Welcome to the **Node.js** master repository! This repo documents a step-by-step practical progression through backend web development — ranging from core Node.js fundamentals to enterprise ORMs, caching, database modeling, authentication, and containerized applications.

---

## 🛠️ Tech Stack & Tools

* **Runtime & Frameworks:** Node.js, Express.js, EJS
* **Databases & ORMs:** MongoDB (Mongoose), MySQL, Drizzle ORM
* **Caching & Queues:** Redis (Queues, Hashsets, Session Expiration)
* **Security & Auth:** JWT, Bcrypt, Role-Based Access Control (RBAC), Cookies & Sessions
* **DevOps & Containers:** Docker, Docker Compose

---

## 📂 Repository Roadmap

### 1. 🟢 Core Fundamentals & Express
* **`01Basics_JS`** – Core JavaScript concepts for backend development.
* **`02FileSystemOperation`** – File system (`fs`) operations and file manipulation.
* **`03ExpressJSRoutingMiddelware`** – Express routing, request pipelines, and custom middleware.
* **`04FormHandlingSessionCookies`** – Form submission, session management, and cookies.

### 2. 🟡 Dynamic UI & Data Persistence
* **`05EJS_DynamicRouting`** – Server-side rendering with EJS templates and dynamic routes.
* **`06SimpleNotesMakingApp`** – Interactive notes-taking web application.
* **`07CRUD_MongoDB`** & **`08IUD_mongo_EJS`** – MongoDB integration using Mongoose for full CRUD workflows.

### 3. 🔴 Security, Authentication & Data Relations
* **`09BCRYPT_JWT`** – Secure password hashing with Bcrypt & stateless authentication using JWT.
* **`10Authentication_Aurthorization`** – Protected routes, user roles, and authorization logic.
* **`11DataAssociation_mongoDB`** & **`12mini_DataAssociation`** – MongoDB schema relationships and data population.

### 4. ⚡ ORMs, Redis Caching & Real-World Apps
* **`13SCATCH`** – Full-stack e-commerce project with product uploads, user cart, and checkout.
* **`14Derizzle_ORM_MYSQL`** – Type-safe relational database management using **Drizzle ORM** & MySQL.
* **`15urlshortener`** – Full-stack URL Shortener service with click analytics.
* **`16nodeRedis`** – High-performance caching, background queues, and session timeouts with **Redis**.
* **`Drizzle_Admin_User_Auth`** – E-commerce backend featuring Admin/Seller roles & Drizzle ORM.
* **`todo-list-app`** – Modern web application fully containerized with **Docker**.

## 💻 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rahul-dusane/Node-js.git
   cd Node-js
   ```

2. **Run any project:**
   ```bash
   cd <folder-name>
   npm install
   npm start
   ```
